# Prospective case intake template

Copy this outline into a new named case only after the owner approves that research scope. This template itself does not select or start a second case.

1. **Question and selection:** case ID, archaeological question, selection rationale, prior exposure to results, inclusion/exclusion criteria, intended test of transferability.
2. **Evidence:** source catalogue with access/read-depth, rights, versions/pages, immutable raw observations, source dependencies and contradictory records.
3. **Physical interpretation:** feature identities and alternatives, preservation/observation-point definitions, chronology associations, missing evidence.
4. **Measurement model:** units, coordinate/reference/north conventions, estimand, membership, uncertainty assumptions and excluded interpretations.
5. **Protocol:** finite scenarios, comparators with equal information, controls, metrics, stopping rules and criteria for inconclusive results; lock before execution.
6. **Implementation:** case-specific adapter, tested calculations, new output location, hashes/environment, failure retention and independent checks.
7. **Acceptance:** reviewed claim-to-evidence links, objections and responses, limitations, contribution decision and publication scope.

Use actual evidence rather than defaulting to Nabta's rounding boxes, target hypotheses or geometry. Shared-code extraction is conditional on demonstrated reuse. Plan/state and acceptance rules must be extended explicitly; the current Nabta validator is not automatically a validator for this case.
