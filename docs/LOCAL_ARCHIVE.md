# Local research archive

The local project retains `legacy/` and `agent_artifacts/` unchanged. They are ignored by Git and are not required to run the numerical reproduction. They contain source PDFs, extracted book text and page images, inherited notebooks/videos, delegate transcripts and historical run trees. A clone does not contain these materials.

Use the source identifiers and printed pages in the evidence ledgers to obtain and inspect primary sources. Local PDF holdings are research copies; no redistribution licence is assumed. Links redirected here are listed in [archive link inventory](archive_links.json), with their original source location. These are explicitly unavailable archive targets in a clone, not evidence that the source was verified anew.

The promoted plans, protocols and manuscript are now maintained under `docs/`. Their earlier versions in agent_artifacts are historical snapshots. New worker packets and review logs stay under `agent_artifacts/`; accepted outputs enter the curated repository only after main-agent review.

For a new maintainer, see the [handoff](HANDOFF.md) and [metadata-only source catalogue](sources/README.md). Selected historical code and diagnostic tables are now public under [support](../support/README.md); source PDFs, page images, worker transcripts and unrelated legacy assets remain excluded.
