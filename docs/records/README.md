# Reviewed research records

Store each new claim-audit or experiment-result JSON as a separate file here. Every file is validated against the dispatched OUTPUT_SCHEMAS.json root by scripts/check_repository.py. An accepted record also needs local evidence hashes and an attributed reviewer. Null printed pages remain allowed when a precise source locator explains an honest access limit; this does not count as primary-page verification. Empty assumptions can describe an unreviewed record, but cannot support an accepted claim. Input hashes are required even for provisional experiment results.

Existing October ledgers remain historical snapshots in data/ and docs/evidence/. They are not silently relabelled as accepted records under this new contract. A well-formed record is necessary for acceptance, never sufficient evidence of truth. Stage closure additionally needs its acceptance receipt and completed dependencies.
