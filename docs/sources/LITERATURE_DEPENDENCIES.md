## Conditional acquisition backlog

These are **not silently assumed to have been obtained or read**, and incomplete entries are not promoted into the finalized reference list:

- Berens (2009), “CircStat: A MATLAB Toolbox for Circular Statistics,” DOI 10.18637/jss.v031.i10: earlier download gap; obtain and assess before adopting those circular procedures.
- Schaefer (1987), “Heliacal Rise Phenomena,” DOI 10.1177/002182868701801103: earlier full-text gap; conditional need if that specific visibility model is used.
- Wendorf and Schild's 2001 volume 2, *The Pottery*: no local copy identified in the earlier audit; needed only if ceramic chronology becomes evidentially necessary. Confirm authorship/edition before final citation.
- Bagnold (1931), *Journeys in the Libyan Desert 1929 and 1930*: exact installment/citation remains unresolved; low-priority history, not a current computational dependency.
- Any new software, catalogue or terrain dataset actually adopted needs its exact version, release identifier and appropriate citation. The existing Python requirements are runtime dependencies; a software-paper citation alone does not identify the installed build.

## Completion rule

Each literature-dependent claim must record source/version, printed locator, read depth, actual relevance, competing evidence and remaining uncertainty in its W1/W2 record. Acquisition and citation formatting close neither W1 nor novelty review. Do not repeatedly request missing field records from the owner; their absence is already recorded. If source access is unavailable to the successor, proceed with unaffected coding or conditional analyses and mark only the dependent primary-source check blocked.
