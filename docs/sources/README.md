# Source acquisition and reading guide

[CATALOGUE.json](CATALOGUE.json) is a metadata-only inventory of 33 source entries, including overlapping chapters/copies and one unavailable article. These are not 33 independent studies. It combines the historical acquisition register with core sources held elsewhere locally. `local_archive_locator` identifies an **excluded** local file, not a path promised in a clone. URLs are inherited acquisition locators, not newly verified availability. DOI values are retained from existing records; null means not established here. Hashes identify files, not reading quality or authenticity by themselves.

The historical `checked` and acquisition fields are dated evidence; later curated notes take precedence. Do not infer full reading from a downloaded PDF. The 1987 candidate is a rejected substitute for the Sahara article; sourcebook copies and handbook/chapter copies overlap.
